# 📱 R-Phone v2.1.2 (SillyTavern 拟真手机通讯扩展)

这是一款为 SillyTavern (酒馆) 设计的沉浸式“R-Phone”拟真手机渲染扩展。它可以将 AI 生成的特定格式文本，自动拦截并渲染为一个真实、可交互的智能手机聊天界面，支持发表情包、语音、转账、发送图片和撤回消息等丰富交互。

## ✨ 核心特性

- **高保真视觉渲染**：完美的双边气泡布局、仿微信/LINE/WhatsApp的沉浸式界面。
- **丰富的媒体支持**：
  - 文字消息
  - 图片与视频展示 (带有固定高度的描述滚动区)
  - 语音消息 (带有动态声波和时长)
  - 转账卡片 (点击可“领取”并改变状态)
  - 定位卡片
  - 撤回消息提示机制
- **动态交互注入**：你可以在界面上直接点击“+”号发送表情包、语音或转账，操作结果会无缝通过系统提示词注入 AI 的上下文，让 AI “看”到你的操作。
- **持久化主题库与快捷切换 (v2.0)**：
  - 内置 4 套经典官方预设（微信、樱花粉、KakaoTalk、WhatsApp）。
  - 支持 **一键存入个人主题库**，随时一键切换角色或全局主题，永久保存防丢失。
  - 支持 **全局配置** 和 **角色专属配置**，一键打包写入角色卡！
- **随心自由拖动 (v2.0)**：悬浮入口按钮与手机悬浮窗均支持在屏幕上任意拖拽移动，并记忆位置。
- **跨层聚合 (Aggregate)**：自动打通上下文，将上下多轮对话中的手机消息无缝拼接成一个连续的聊天记录界面。

## 📦 安装方法

1. 打开你的酒馆根目录，进入 `public/scripts/extensions/third-party/`。
2. 将本扩展文件夹放入其中。
3. 刷新酒馆页面，点击顶部导航栏的“扩展插件(拼图图标)”，找到 **📱 R-Phone** 菜单即可开启设置。

*(注：请确保文件夹名称与 `index.js` 中配置的 `FOLDER_NAME` 完全一致)*

## 📝 给 AI 设定的系统提示词 (Prompt / 世界书)

要让 AI 输出手机界面并识别用户的手机输入，建议将以下规范加入到角色的 System Prompt (系统设定) 或 World Book (世界书) 中：

```markdown
## 手机消息格式规范

当剧情中涉及角色使用手机发送/接收消息时，请使用以下标记格式输出。系统会自动将其渲染为手机聊天界面。

### 基本结构
# 1. 角色与 {{user}} 私聊 (contact 为对方角色名或备注)
[phone:contact=聊天对象名]
消息列表...
[/phone]

# 2. NPC 与 NPC 私聊视角 (pov 为拿着手机发信息的持机人角色名)
[phone:聊天对象名 pov=持机人名]
消息列表...
[/phone]

# 3. 群聊
[phone:群聊名称]
消息列表...
[/phone]

### 核心规则
- **contact 属性**：聊天界面顶部显示的聊天对象名（如对方角色名、备注或群名）。支持简写 `[phone:角色名]`。
- **{{user}} 的输入识别**：
  {{user}} 发送的带有 `[@联系人]` 会话头或以 `〖...〗` 包裹的消息被视为手机聊天内容。例如：
  [@{{char}}]
  〖在干嘛呢？〗
  〖表情：流泪〗
  这代表 {{user}} 正在使用手机向指定的联系人发送短信，请根据此情境以手机短信方式回复。
- **角色与 {{user}} 的私聊**：你只需以自身角色身份（from={{char}}）回复消息，无需替 {{user}} 编写或复述手机发言。
- **NPC 之间的私聊（持机人视角）**：
  当剧情描写 NPC 之间私下发短信（如背地密谋、幕间展示）时，必须加上 `pov=持机人名`，如 `[phone:小红 pov=小蓝]`。
  持机人的消息标注 `from=小蓝`（渲染在右侧）；对方的消息标注 `from=小红`（渲染在左侧）。该视角会独立隔离，绝不入侵 {{user}} 的私聊窗口！
- **群聊**：会话名为群名（如 `[phone:班级群]`），各成员发言标注各自的 `from=角色名`。
```

## 🎨 角色专属配置与导出

在扩展设置面板中，你可以管理你的手机主题和表情包。

### 1. 角色专属 vs 全局配置
扩展支持设置**全局默认**的表情包和主题皮肤。
当你加载一个特定角色时，你可以为该角色配置专属的皮肤（比如给这个角色换成粉色 LINE 主题）和专属的表情包映射。

### 2. 表情包格式 (JSON)
在文本框中输入 JSON 格式：
```json
{
  "摸头": "https://img.example.com/pat.gif",
  "流泪": "https://img.example.com/cry.png"
}
```
当你在手机界面点击“+”并发送 `摸头` 时，UI 就会自动渲染出这张图片。

### 3. 主题系统（主题库 & 随心切换）
你可以随时随地随心更换手机 UI 的皮肤外观！
- **✨ 官方预设开箱即用**：内置 4 套精美主题：🟢 微信经典、🌸 樱花初绽 (Sakura)、🟡 KakaoTalk (可可黄)、📱 WhatsApp (经典绿白)，下拉即可一键切换！
- **📚 专属主题库持久保存**：将任何 AI 生成或自调的 CSS 粘贴到编辑框后，点击 **“⭐ 存入主题库”** 并命名（如“赛博朋克”、“极简黑白”），便会永久保存在本地主题库中。**只要存过就能随时翻出来一键切换，除非你主动选择删除！**
- **⚡ 一键多端应用**：
  - **🎭 应用给当前角色**：仅为当前聊天的角色定制专属聊天皮肤。
  - **🌐 应用为全局主题**：设为全部角色的默认外观。
  - **📋 载入代码编辑**：把任意已存主题加载到编辑框进行二次微调。
  - **🗑️ 删除主题**：随时管理清理不需要的自定义主题（带确认防误删）。

### 4. 写入角色卡 (Export)
配置好完美的专属主题和专属表情包后，点击 **“写入角色卡”**。这些配置会被自动存入角色卡的扩展数据区。
之后无论是分享这张 PNG 还是在新设备上加载，你的绝美手机 UI 配置都会跟随角色卡完美再现！

## 🛠️ 交互面板操作指引

当手机渲染在屏幕上后，注意底部有一个绿色的 **“+” 号输入条**：
1. **点击加号** 会弹出二级菜单：
   - **📸 图片/视频**：输入文字描述（或带链接），以媒体卡片形式发送。
   - **😊 表情**：输入你在 JSON 中配置的键值（如“流泪”），发送表情包。
   - **💰 转账**：输入数字进行转账。
   - **🎤 语音**：输入秒数，发送语音条。
2. 发送后，UI 会立即展示一个半透明的“预览气泡”。
3. 在你点击酒馆默认的发送按钮（继续对话）时，这些操作记录会自动被打包注入到 `System Note` 中发给 AI，告诉 AI：“用户刚才在手机上给你发了 520 块钱，并发送了一个【流泪】表情包”。
